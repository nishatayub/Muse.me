# Vercel Deployment Configuration

## Backend (Python FastAPI)
- Runtime: Python 3.11
- Handler: api/index.py

## Frontend (Next.js)
- Framework: Next.js 14
- Node version: 18+

## Environment Variables (Set in Vercel Dashboard)
NEXT_PUBLIC_API_URL=https://muse-me-backend.vercel.app
OPENROUTER_API_KEY=sk-or-v1-YOUR_KEY
SPOTIFY_CLIENT_ID=YOUR_ID
SPOTIFY_CLIENT_SECRET=YOUR_SECRET
REPLICATE_API_TOKEN=YOUR_TOKEN (optional)

## Deployment Steps

### 1. Remove .env from Git
git rm --cached backend/.env
git commit -m "Remove .env"
git push origin main

### 2. Deploy to Vercel
- Go to https://vercel.com
- Import GitHub repo: kalviumcommunity/Muse.me
- Root directory: (leave blank - auto-detect)
- Environment variables (add in Vercel dashboard):
  * NEXT_PUBLIC_API_URL
  * OPENROUTER_API_KEY
  * SPOTIFY_CLIENT_ID
  * SPOTIFY_CLIENT_SECRET
- Deploy

### 3. Update Spotify Dashboard
- Go to https://developer.spotify.com/dashboard
- Edit Muse.me app
- Redirect URI: https://muse-me.vercel.app/auth/spotify/callback

### 4. Your App is Live!
- Frontend: https://muse-me.vercel.app
- Backend: https://muse-me-backend.vercel.app
- API Docs: https://muse-me-backend.vercel.app/docs
